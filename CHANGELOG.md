# Changelog

All notable changes to ClipVault are documented in this file.

## [1.0.0] — 2026-10-27

First public release.

### Added
- Super+V history flyout with search, pin, delete, and clear
- Top-bar tray icon with recent items, **All items** (opens the flyout), and **Clear all**
- Text + image history (JPEG/PNG/WebP/BMP/GIF, stored as PNG)
- Deduplication by text and image hash
- Follows the system light/dark theme
- GNOME-safe clipboard watch (XWayland / GDK — no `wl-clipboard` polling)
- Autostart, dock icon, and `install.sh` / `uninstall.sh`
- Debian package (`clipvault_1.0.0_all.deb`)
