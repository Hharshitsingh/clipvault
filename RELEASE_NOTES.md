# ClipVault 1.0.0

Windows 11–style clipboard history for Linux — Super+V, tray icon, pin, search, images.

## Install

**Debian / Ubuntu**

```bash
sudo apt install ./clipvault_1.0.0_all.deb
clipvault
```

**From source**

```bash
git clone https://github.com/Hharshitsingh/clipvault.git
cd clipvault
chmod +x install.sh
./install.sh
```

Then press **Super+V** (or click the tray icon). Copy with Ctrl+C, click an item, paste with Ctrl+V.

## Highlights

- Text + image history, pin, search, clear
- GNOME-safe: no `wl-clipboard` polling, no keyboard lag, no “wl-clipboard is ready” spam
- Follows your light/dark theme
